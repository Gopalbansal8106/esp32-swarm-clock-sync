🚀 HOW TO RUN
═══════════════════════════════════════════════════════════════════════════════

OPTION 1: AUTOMATIC (RECOMMENDED)

Windows:
  → Double-click: start.bat

macOS/Linux:
  → Terminal: chmod +x start.sh && ./start.sh


OPTION 2: MANUAL

Windows:
  1. python -m venv venv
  2. venv\Scripts\activate
  3. cd backend
  4. pip install -r requirements.txt
  5. python main.py

macOS/Linux:
  1. python3 -m venv venv
  2. source venv/bin/activate
  3. cd backend
  4. pip install -r requirements.txt
  5. python main.py

THEN:
  → Open browser: http://localhost:8000

⚙️ CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════

Easy customization in config.py:

  INITIAL_NODES = 8              # Starting nodes (2-20)
  MAX_NODES = 20                 # Maximum allowed
  LATENCY_MEAN_MS = 20           # Network latency
  LATENCY_STD_MS = 5             # Latency variation
  DRIFT_RATE_MIN = -100          # Clock drift range (PPM)
  DRIFT_RATE_MAX = 100
  CONVERGENCE_SPEED = 0.05       # Sync convergence rate (0-1)
  SERVER_PORT = 8000             # Web server port

Can also edit:
